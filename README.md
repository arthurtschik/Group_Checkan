# Group Checkan

Android-App zum Abhaken der Anwesenheit von Kindern in Betreuungsgruppen – schnell, übersichtlich und offline.
Alle Daten bleiben verschlüsselt auf dem Gerät: kein Konto, keine Cloud, keine Werbung, kein Tracking.

**Download:** <https://arthurtschik.github.io/Group_Checkan/> oder direkt unter [Releases](../../releases)
(Android 7.0 oder neuer). Updates gibt es auch direkt in der App: *Einstellungen → App-Update*.

## Echtheit prüfen

Alle offiziellen Versionen sind mit demselben Schlüssel signiert. Fingerabdruck des Zertifikats:

```
SHA-256: 4C:C4:B3:A7:45:64:A3:E2:58:F8:53:82:4E:19:20:5F:1E:CF:7C:FA:F2:FD:AB:9D:23:6C:B0:FB:8D:95:8E:04
```

Prüfen lässt sich das zum Beispiel mit *App Manager* direkt auf dem Handy oder mit
`apksigner verify --print-certs Group-Checkan.apk`. Stimmt der Wert nicht überein, bitte nicht installieren.

Wie die App und die Update-Kette geschützt sind: [SECURITY.md](SECURITY.md)
